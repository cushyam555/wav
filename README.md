# Sample to WAV 1.1

โปรแกรม Windows แบบพกพาสำหรับแยกเสียง SF2/SF3 เป็น WAV และบันทึกเสียงทีละคีย์ผ่าน Kontakt การแปลงและบันทึกทำในเครื่อง ไม่มีการอัปโหลดเสียง

## ใช้งานบน Windows โดยไม่ติดตั้ง

รองรับ Windows 10/11 แบบ x64 ไปที่ [GitHub Releases](https://github.com/cushyam555/wav/releases/latest) แล้วดาวน์โหลด `Sample-to-WAV-1.1.0-Windows-x64.exe` ในหัวข้อ Assets เปิดใช้งานได้ทันที ลาก SF2/SF3 มาวางและกดดาวน์โหลด WAV ไม่ต้องติดตั้ง Node.js, Python หรือเปิดเว็บเซิร์ฟเวอร์ หาก repository เป็น private ต้องลงชื่อเข้าใช้บัญชีที่เข้าถึงได้

ทุกครั้งที่ push เข้า main ระบบ GitHub Actions จะทดสอบ สร้าง EXE บน Windows และเผยแพร่ release พร้อมไฟล์ EXE อัตโนมัติ หากยังไม่มี release ให้ตรวจผลที่ [Actions](https://github.com/cushyam555/wav/actions/workflows/windows.yml) ต้องรอขั้นตอน Publish downloadable Windows release สำเร็จก่อนดาวน์โหลด

ไฟล์โปรแกรมยังไม่ได้ลงลายเซ็นดิจิทัล Windows อาจแสดงข้อความเตือนผู้เผยแพร่ที่ไม่รู้จัก ชุดเสียงยังมีข้อจำกัดตามรายการด้านล่าง

## รันจากซอร์ส / สร้าง EXE

ต้องมี Node.js 22 ขึ้นไป สำหรับการสร้าง EXE แนะนำ Windows 10/11 x64

```sh
npm ci
npm start
npm test
npm run dist:win
```

ไฟล์ EXE อยู่ใน `dist/` GitHub Actions ใช้คำสั่งเดียวกันบน Windows และเก็บ EXE เป็น artifact ไม่ได้นำไฟล์ขนาดใหญ่ไปใส่ในประวัติ Git

## เปิดเป็นเว็บ (ทางเลือก)

ต้องมี Python 3 สำหรับเซิร์ฟเวอร์ และ Node.js 18 ขึ้นไปสำหรับทดสอบ

```sh
cd /workspace/wav
npm run start:web
```

เปิดเบราว์เซอร์ที่พอร์ต 8000 ของเครื่องที่รันโปรแกรม เลือกไฟล์หรือลากหลายไฟล์ลงในช่อง แล้วกดดาวน์โหลด WAV ทั้งหมด

```sh
npm test
```

## รองรับอะไรบ้าง

- SF2 แบบ RIFF sfbk: แยก samples ที่ฝังใน smpl/sm24 เป็น PCM WAV 16/24-bit โดยคง sample rate เดิม ช่องซ้ายและขวาของ stereo ถูกส่งออกเป็นไฟล์ mono แยกกัน ชื่อไฟล์มีเลขลำดับเพื่อป้องกันชื่อซ้ำ
- SF3 แบบ RIFF sfbk: ใช้ byte offsets ของ sample ที่มี Vorbis flag (0x10) ถอด Ogg Vorbis เป็น PCM WAV 16-bit ผ่าน OfflineAudioContext ที่ sample rate ของ sample ไม่ใช่แค่เปลี่ยนนามสกุลไฟล์ ข้อผิดพลาดของแต่ละ sample จะแสดงแยกกัน
- SFZ: อ่าน sample และ default_path แบบพื้นฐาน ต้องเลือกไฟล์เสียงที่อ้างอิงมาด้วย ค้นหาด้วยชื่อไฟล์ และรายงานชื่อซ้ำ/ไฟล์ขาด ไม่รองรับ include, macro หรือการเปลี่ยน default_path หลายครั้ง
- WAV แบบ RIFF: คัดลอกต้นฉบับโดยไม่เข้ารหัสใหม่
- AIFF, MP3, OGG, FLAC, M4A, AAC: ใช้ Web Audio ถอดรหัสเมื่อเบราว์เซอร์รองรับ แล้วบันทึกเป็น PCM 16-bit อาจ resample ตาม AudioContext จึงไม่ได้คง bit depth และ sample rate ต้นฉบับเสมอไป

การแยก SF2/SF3 ให้ samples ต้นฉบับ ไม่ใช่เรนเดอร์ทุกโน้ต MIDI และไม่รวม envelope, loop, filter, preset หรือเอฟเฟกต์ เครื่องดนตรีหลายคีย์อาจใช้ sample เดียวกัน ไม่มีการสร้างเสียงเพิ่มให้ครบทุกคีย์

## บันทึกผ่าน Kontakt (Windows)

โหมดนี้ทำงานกับ **เสียงที่ Kontakt เล่นออกมา** ไม่ใช่ตัวอ่าน/ถอดรหัส NKI/NKM ในตัว โปรแกรมไม่ได้รวม Kontakt, ชุดเสียง หรือ MIDI driver มาให้

1. ติดตั้ง Kontakt (หรือ Player ถ้ารองรับชุดเสียงนั้น) และเปิดชุดเสียง NKI/NKM ให้เล่นได้ตามปกติ ใช้ไลเซนส์ที่ชุดเสียงต้องการ
2. ติดตั้งพอร์ต MIDI เสมือน เช่น loopMIDI แล้วสร้างพอร์ต `SampleToWAV` เปิดพอร์ตนี้เป็น MIDI input ใน Kontakt
3. เลือก MIDI channel ของเครื่องดนตรีใน Kontakt เช่น channel 1 สำหรับ NKM ที่มีหลายเครื่องให้เลือก channel ของแต่ละเครื่องเพื่อบันทึกแยก หรือ Omni เพื่อบันทึกเสียงรวมตามการตั้งค่าเครื่องดนตรี
4. ตั้ง Kontakt Audio เป็น WASAPI/shared และส่งไปอุปกรณ์ playback ปกติ/default ของ Windows ให้ตรวจสอบก่อนว่าเสียงระบบปกติและ Kontakt ใช้อุปกรณ์เดียวกัน ASIO/exclusive อาจไม่ส่งเสียงเข้า system loopback
5. ในแท็บ **บันทึกผ่าน Kontakt** กดค้นหา MIDI เลือกพอร์ตเดียวกันและ channel ให้ตรง เลือก **เสียงระบบ Windows** หรือ audio input ที่รับ loopback จาก Kontakt (ต้องตั้ง routing ให้ถูกต้องเอง)
6. กด **ทดสอบเสียง 1 คีย์** และฟังไฟล์ทดสอบ ให้แน่ใจว่าเป็นเสียง Kontakt ที่ต้องการ ต้องทดสอบใหม่เมื่อเปลี่ยนการตั้งค่า
7. เลือกโฟลเดอร์ กำหนดช่วง MIDI notes 0–127 (60 = C4), velocity 1–8 ค่า, จำนวนรอบ 1–8, เวลากดคีย์, ระยะเสียงหลังปล่อย และช่วงพัก แล้วเริ่มบันทึก

ผลลัพธ์เป็น WAV stereo PCM 16-bit ที่ sample rate ของ AudioContext (ร้องขอ 48 kHz) มีช่วงนำ 0.15 วินาทีสำหรับ MIDI/driver latency ชื่อไฟล์ระบุ MIDI note, velocity, รอบ เช่น `key060_C4_v100_r1.wav` บันทึกลงโฟลเดอร์ย่อยที่สร้างใหม่ทีละไฟล์ พร้อม `manifest.json` ระบุพารามิเตอร์, peak, sample rate, frames และสถานะ complete/stopped/failed ไฟล์ที่สำเร็จจะคงอยู่เมื่อยกเลิกหรือเกิดข้อผิดพลาด บันทึกชุดใหม่ต้องเลือกโฟลเดอร์อีกครั้ง

การบันทึกใช้เวลาจริง ไม่ใช่ offline bounce ระหว่างบันทึกควรปิดเพลง/การแจ้งเตือน เพราะ system loopback รวมเสียงจากแอปอื่นด้วย เสียงถูกตรวจว่าไม่เงียบ แต่โปรแกรมแยกไม่ได้ว่าเป็นเสียง Kontakt หรือเสียงระบบอื่น ไม่ normalize เสียงอัตโนมัติ หากแจ้ง clipping ให้ลด volume ใน Kontakt แล้วบันทึกใหม่

ปุ่มหยุดจะยกเลิก MIDI ที่ค้างในคิว ปิด sustain และส่ง all-notes-off/all-sound-off ระบบหยุดเมื่อได้เสียงเงียบ (peak ต่ำกว่า 0.00001) หรืออุปกรณ์ที่ใช้งานหลุด หากคีย์นั้นอยู่นอกช่วงเครื่องดนตรีให้ปรับช่วงคีย์ ไม่ถือว่าการบันทึกเสียงเงียบเป็นความสำเร็จ โปรแกรมไม่เปลี่ยน preset/articulation/keyswitch อัตโนมัติ การทำซ้ำช่วยบันทึก round robin ได้เมื่อเครื่องดนตรีตั้งไว้ให้เปลี่ยนเสียงเอง

ชุดเสียงที่เข้ารหัสใช้ได้ผ่านโหมดบันทึกเฉพาะเมื่อ Kontakt เปิดและเล่นได้ตามสิทธิ์ของคุณ ไม่มีฟีเจอร์ปลดการเข้ารหัส ROM ที่ไม่มีเสียงฝังในไฟล์ยังต้องใช้แหล่งเสียงจริง ไม่สามารถสร้างเสียงที่ไม่มีอยู่ในไฟล์ขึ้นมาได้

## ข้อจำกัดและการทดสอบ

แยกไฟล์ SF2/SF3 และ ZIP ใช้หน่วยความจำทั้งไฟล์และผลลัพธ์ ZIP ไม่รองรับ ZIP64 (เกิน 4 GB/65,535 รายการ) ให้แบ่งเป็นชุดเล็ก ส่วนโหมด Kontakt เขียนลงดิสก์ทีละเสียง จำกัด 2048 เสียงต่อชุด เพื่อลดการใช้หน่วยความจำ

ชุดทดสอบ 15 รายการครอบคลุม SF2 16/24-bit, SF3 offsets, decoder errors, ROM, SFZ, WAV/ZIP, MIDI scheduling, cancellation และ AudioWorklet frame counts ไฟล์ `tests/fixtures/two-tones.sf3` เป็น fixture สังเคราะห์ที่มี Ogg Vorbis สอง samples ความถี่ 440 Hz ไม่ใช่ชุดเครื่องดนตรีสำหรับนำไปเล่น

ทดสอบหน้าจอ Electron กับตัวถอดรหัส Vorbis จริงและเครื่องดนตรี MIDI จำลองที่สร้างเสียงผ่าน AudioWorklet/IPC/ไฟล์ WAV จริง การเชื่อมต่อ Kontakt และ Windows WASAPI loopback ต้องตรวจเพิ่มเติมบนเครื่อง Windows ที่ติดตั้ง Kontakt และ MIDI driver ยังไม่ได้ยืนยันด้วย Kontakt จริงในสภาพแวดล้อม Linux นี้
