# Sample to WAV

โปรแกรมเว็บสำหรับลากไฟล์มาวาง แล้วดาวน์โหลดเสียง WAV ทีละไฟล์หรือรวมเป็น ZIP การประมวลผลทำในเบราว์เซอร์ ไม่มีการอัปโหลดไฟล์และไม่มีไลบรารีภายนอก

## ใช้งานบน Windows โดยไม่ติดตั้ง

รองรับ Windows 10/11 แบบ x64 ไปที่ [GitHub Releases](https://github.com/cushyam555/wav/releases/latest) แล้วดาวน์โหลด `Sample-to-WAV-1.0.0-Windows-x64.exe` ในหัวข้อ Assets เปิดใช้งานได้ทันที ลาก SF2 มาวางและกดดาวน์โหลด WAV ไม่ต้องติดตั้ง Node.js, Python หรือเปิดเว็บเซิร์ฟเวอร์ หาก repository เป็น private ต้องลงชื่อเข้าใช้บัญชีที่เข้าถึงได้

ทุกครั้งที่ push เข้า main ระบบ GitHub Actions จะทดสอบ สร้าง EXE บน Windows และเผยแพร่ release พร้อมไฟล์ EXE อัตโนมัติ หากยังไม่มี release ให้ตรวจผลที่ [Actions](https://github.com/cushyam555/wav/actions/workflows/windows.yml) ต้องรอขั้นตอน Publish downloadable Windows release สำเร็จก่อนดาวน์โหลด

ไฟล์โปรแกรมยังไม่ได้ลงลายเซ็นดิจิทัล Windows อาจแสดงข้อความเตือนผู้เผยแพร่ที่ไม่รู้จัก ชุดเสียงยังมีข้อจำกัดตามรายการด้านล่าง

## รันจากซอร์ส / สร้าง EXE

ต้องมี Node.js 22 ขึ้นไป สำหรับการสร้าง EXE แนะนำ Windows 10/11 x64

```sh
npm ci
npm start
npm test
npm run dist:win
```

ไฟล์ EXE อยู่ใน `dist/` GitHub Actions ใช้คำสั่งเดียวกันบน Windows และเก็บ EXE เป็น artifact ไม่ได้นำไฟล์ขนาดใหญ่ไปใส่ในประวัติ Git

## เปิดเป็นเว็บ (ทางเลือก)

ต้องมี Python 3 สำหรับเซิร์ฟเวอร์ และ Node.js 18 ขึ้นไปสำหรับทดสอบ

```sh
cd /workspace/wav
npm run start:web
```

เปิดเบราว์เซอร์ที่พอร์ต 8000 ของเครื่องที่รันโปรแกรม เลือกไฟล์หรือลากหลายไฟล์ลงในช่อง แล้วกดดาวน์โหลด WAV ทั้งหมด

```sh
npm test
```

## รองรับอะไรบ้าง

- SF2 แบบ RIFF sfbk: แยก samples ที่ฝังใน smpl/sm24 เป็น PCM WAV 16/24-bit โดยคง sample rate เดิม ช่องซ้ายและขวาของ stereo ถูกส่งออกเป็นไฟล์ mono แยกกัน ชื่อไฟล์มีเลขลำดับเพื่อป้องกันชื่อซ้ำ
- SFZ: อ่าน sample และ default_path แบบพื้นฐาน ต้องเลือกไฟล์เสียงที่อ้างอิงมาด้วย ค้นหาด้วยชื่อไฟล์ และรายงานชื่อซ้ำ/ไฟล์ขาด ไม่รองรับ include, macro หรือการเปลี่ยน default_path หลายครั้ง
- WAV แบบ RIFF: คัดลอกต้นฉบับโดยไม่เข้ารหัสใหม่
- AIFF, MP3, OGG, FLAC, M4A, AAC: ใช้ Web Audio ถอดรหัสเมื่อเบราว์เซอร์รองรับ แล้วบันทึกเป็น PCM 16-bit อาจ resample ตาม AudioContext จึงไม่ได้คง bit depth และ sample rate ต้นฉบับเสมอไป

การแยก SF2 ให้ samples ต้นฉบับ ไม่ใช่เรนเดอร์ทุกโน้ต MIDI และไม่รวม envelope, loop, filter, preset หรือเอฟเฟกต์ เครื่องดนตรีหลายคีย์อาจใช้ sample เดียวกัน ไม่มีการสร้างเสียงเพิ่มให้ครบทุกคีย์

ยังไม่รองรับ NKI, NKM, SF3, ROM samples หรือชุดเสียงที่เข้ารหัส ไฟล์ใหญ่ใช้หน่วยความจำทั้งไฟล์และผลลัพธ์ ZIP ไม่รองรับ ZIP64 (เกิน 4 GB/65,535 รายการ) หากเบราว์เซอร์หน่วยความจำไม่พอ ให้แบ่งแปลงเป็นชุดเล็ก

ชุดทดสอบใช้ SF2 สังเคราะห์เพื่อตรวจ PCM, 24-bit, ไฟล์เสีย, SFZ, stereo และ ZIP ควรทดสอบเพิ่มเติมกับ SoundFont จริงของผู้ใช้และเบราว์เซอร์เป้าหมาย
